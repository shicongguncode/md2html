# 01: 基础转换打底

**What to build:** 命令行传入一个 Markdown 文件，在源文件旁生成同名 HTML。页面直接套用参考样本的完整样式：暖米色纸张卡片、深浅色跟随系统并可手动切换、响应式、打印样式；Markdown 的标题、段落、列表、引用、表格、行内代码、链接、分隔线、图片都正确渲染；第一个一级标题作为页面标题，没有则用文件名；输入文件缺失时给出可读错误并非零退出。这是贯穿命令行、转换核心、页面模板、文件读写的第一个可演示切片。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 命令行传入一个 `.md` 返回退出码 0，源文件旁出现同名 `.html`
- [x] 生成的 HTML 是单文件：样式与脚本全部内联，打开时不请求任何外部资源
- [x] 标题、段落、有序/无序列表、引用、表格、行内代码、链接、分隔线正确渲染
- [x] 图片保持 Markdown 中的相对路径，不被改写或内嵌，且不超出正文宽度
- [x] 第一个一级标题成为页面标题；没有一级标题时使用文件名（不含扩展名）
- [x] 深浅色跟随系统，右上角按钮可手动切换并在刷新后保持
- [x] 窄屏时正文变单栏、字号略小；打印时隐藏切换按钮与阴影边框
- [x] 含空格和中文的文件名可正常转换；同名 HTML 直接覆盖
- [x] UTF-8（含 BOM）与 GB18030 编码的输入都能读取
- [x] 输入文件不存在时输出可读错误信息，并以非零状态退出
- [x] 有通过命令行接缝的自动化测试，覆盖转换成功、标题取值、覆盖行为、错误退出
