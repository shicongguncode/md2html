# 05: 拖拽入口与批量转换

**What to build:** 提供一个 Windows 批处理入口，把 `.md` 文件拖上去就能转换；拖多个文件时逐个转换，并且只有单个文件时才自动打开浏览器。命令行同样支持一次传入多个路径。转换失败时窗口停留显示错误、不闪退，中文和带空格的路径都能正常工作。

**Blocked by:** 01（基础转换打底）。

**Status:** ready-for-agent

- [ ] 拖一个 `.md` 到批处理文件上：生成同名 HTML 并自动用默认浏览器打开
- [ ] 拖多个文件：逐个生成 HTML，不自动打开浏览器
- [ ] 命令行一次传多个路径时，行为与拖拽批量一致
- [ ] `--open` 在单文件时打开浏览器，在多文件时不为每个文件打开
- [ ] 转换失败时窗口保留并显示可读错误，不闪退
- [ ] 中文路径、含空格路径下拖拽与批量都正常
- [ ] 有自动化测试覆盖多路径批量转换与开关解析；拖拽 `.bat` 做一次手工冒烟并记录结果
