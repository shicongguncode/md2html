# 03: 代码高亮

**What to build:** 带语言标记的围栏代码块在生成阶段完成语法高亮，配色与暖米色/橙色主题协调，深浅色下都能看清；高亮样式自动注入页面，不依赖浏览器端脚本或外部样式表。未知语言按纯文本输出，行内代码不受影响。

**Blocked by:** 01（基础转换打底）。

**Status:** ready-for-agent

- [ ] 带语言的代码块输出带高亮标记，常见语言（Python、JavaScript、Bash、HTML、CSS、JSON）着色正确
- [ ] 配色与页面暖色主题协调，浅色与深色模式下代码都可读
- [ ] 高亮样式随页面内联注入，打开 HTML 时不加载任何外部资源
- [ ] 未知语言或未标语言的代码块按纯文本渲染，不报错、不丢失内容
- [ ] 行内代码不参与语法高亮，只保留行内代码样式
- [ ] 有自动化测试断言高亮标记存在、样式已注入、未知语言可正常转换
