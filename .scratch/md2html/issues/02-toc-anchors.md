# 02: 目录与标题锚点

**What to build:** 转换时给二级、三级标题生成稳定锚点，并在页面左侧生成吸顶目录；目录只列这两级，点击可跳转，滚动时高亮当前章节。传 `--no-toc` 时目录消失，正文改为居中单栏。完成后长文档可以直接靠目录定位。

**Blocked by:** 01（基础转换打底）。

**Status:** ready-for-agent

- [ ] 二级标题生成 `sec-<序号>` 锚点，三级标题生成 `item-<序号>` 锚点，序号从 1 起在各自级别内递增
- [ ] 左侧目录只收录二级、三级标题，层级嵌套正确
- [ ] 点击目录条目能跳到对应章节，标题滚动定位留有顶部间距
- [ ] 滚动页面时目录高亮当前所在章节
- [ ] 传 `--no-toc` 时没有目录区域，正文为居中单栏
- [ ] 没有二级、三级标题时目录区域不出现，页面不报错
- [ ] 有自动化测试覆盖锚点命名、目录内容、`--no-toc` 的布局差异
